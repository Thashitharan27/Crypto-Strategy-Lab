# Phase 1b: actual trade-report schema mapping audit

Status: source-code inspection, not a certified live or historical fixture. Based on `crypto_strategy_lab/engine.py` (`_pair_row` and `_pos_cols`), `crypto_strategy_lab/research_reporting.py`, and `crypto_strategy_lab/research_adapters.py`. Existing native completed runs export the engine's trade DataFrame to `trade_list.csv`.

## Source fields and exact meaning

| Parity concept | Existing row evidence | Caveat |
| --- | --- | --- |
| Trade identity | `trade_id`, `pair_id`, `result_type` | `trade_id` contains pair ID plus row kind. Explicitly check aggregate vs leg before comparing |
| Direction | `side`, `trade_direction` | `side` is primary position; flips and combined records require comparison of both |
| Signal timestamps | `signal_candle_time`, `signal_available_at`, research signal fields | Do **not** substitute candle opening for signal availability |
| Entry timestamps | `entry_time`, `actual_entry_timestamp`, `strategy_entry_time` | `entry_time` is assigned strategy entry time, not necessarily actual intrabar limit fill; use `actual_entry_timestamp` for execution comparison, separately compare `entry_time` |
| Entry price | `entry_price`, `actual_entry_price`, `long_entry_price`, `short_entry_price` | Pair row primary price vs leg fields |
| Stop and target | `long_original_sl`, `long_tp`, `short_original_sl`, `short_tp`; plus original plan fields | Position trailing/current stops are not initial stops; targets can be absent on trailing-only plans |
| Exit timestamps, price, reason | `exit_time` at pair level; `long_exit_time` / `short_exit_time`, `long_exit_price` / `short_exit_price`, `long_final_exit_reason` / `short_final_exit_reason` | Pair-level exit time is not interchangeable with each leg's exit time |
| Quantity | `long_quantity`, `short_quantity` | No safely inferred generic quantity for combined legs |
| Fees | `pair_total_fees`, `long_total_fees`, `short_total_fees` | Preserve pair-vs-leg definition |
| Net PnL and R | `pair_net_pnl`, `pair_net_r`, `long_net_pnl`, `short_net_pnl`, `long_net_r`, `short_net_r` | `pair_net_r` uses configured sizing budget; leg R may follow different semantics |
| Slippage | Configured execution model and actual execution prices | A directly recorded per-trade numeric slippage column is **not established** in this audit; cannot invent one |

## Consequences for PR #504 and golden fixtures

- PR #504 requires an explicit complete mapping. It **must not** be invoked against actual runs with fabricated columns or numbers. Its generic 15-field format is an intermediate check contract; not proof that all native report fields can be represented.
- Add a separate **native trade-list adapter** only after confirming row granularity and optional fields in actual completed-run examples. Compare pair-level rows separately from long/short leg rows, including partial fills. Do not rename the legacy `entry_time` column, alter the writer, or change the engine.
- Consider extending the parity contract so native rows preserve **both** scheduled entry and actual fill timestamp, per-leg stop changes, partial fill events, and source/data identity. A single synthetic `exit_price` cannot represent a trade closed in multiple fills.
- Frozen fixture metadata must include commit SHA, config snapshot hash, market-data source hash, timeframe, interval and 1m coverage. Golden outputs require stable fixtures, not the user's mutable local Data Hub.
- Start by recording a **schema-only probe** on native trades generated by existing test fixtures, then create fixed long, short, pending Fib and partial-exit golden runs, comparing all native columns relevant to trading.
- No numerical trade-level parity conclusion is possible from static code inspection alone.

## Phase gate

Do not start write-capable FastAPI endpoints or retire PySide6 until exact source schema mapping and **real** frozen historical backtest comparisons pass. Continue read-only architecture extraction independently when safe. Leave PR #501 on hold until its limit-touch resolver is proved nonduplicative and causally equivalent.
